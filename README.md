# Viewline Aerial

Official static website for Viewline Aerial, Charlotte, North Carolina.

## Run locally
Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages
Go to repository **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then **Save**. The expected address is https://kreeceman.github.io/viewline_aerial/ once deployment completes.

## Before public promotion
- Replace the abstract hero with approved, optimized Viewline Aerial footage or photography.
- Add actual portfolio images/video with permission to display them.
- Connect and test a contact form or add a verified business contact email.
- Confirm all business claims, service offerings, and any pricing.

No visitor inquiries are collected by this initial release. Do not publish personal contact information or credentials in source code.
